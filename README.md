# 📊 End-to-End E-Commerce Analytics Project

## 📌 Overview

This project presents a complete **end-to-end data analytics pipeline** using **Python, SQL, and Power BI** to analyze e-commerce sales performance, customer behavior, and profitability.

The goal is to transform raw transactional data into **actionable business insights** through data cleaning, querying, and interactive dashboarding.

---

## ⚙️ Tech Stack

* **Python** (Pandas, NumPy, Matplotlib, Seaborn)
* **SQL** (MySQL)
* **Power BI**
* **GitHub** (Project Hosting)

---

## 🚀 Project Workflow

1. **Data Collection**

   * E-commerce transactional dataset

2. **Data Cleaning & Preprocessing (Python)**

   * Handling data types
   * Feature engineering (year, month, etc.)
   * Data validation

3. **Database Management (SQL)**

   * Created relational schema:

     * Customers
     * Products
     * Orders
   * Performed analytical queries using JOINs, aggregations, and window functions

4. **Data Visualization (Power BI)**

   * Built interactive dashboards
   * Created KPIs and DAX measures
   * Designed 3 report pages:

     * Executive Overview
     * Customer & Behavior Analysis
     * Profitability & Operations

---

## 📊 Key Insights

* **Electronics category dominates revenue**, acting as the primary growth driver.
* **Higher discounts negatively impact profit margins**, reducing overall profitability.
* **Return rates increase with longer delivery times**, indicating logistics inefficiencies.
* **Senior and adult customers contribute the majority of revenue**, reflecting stronger purchasing power.
